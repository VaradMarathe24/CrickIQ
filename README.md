# Put your IPL datasets here for automatic analysis

Copy these CSV files into this folder before running or deploying the project:

- ipl.csv
- IPL 2025 player statistics.csv
- ipl tweets.csv
- ipl_batsman.csv
- ipl_bowler.csv
- matches.csv

The Dashboard automatically scans this folder as soon as the user clicks **Start analysis** on the Landing page. Dashboard upload is optional and is intended only for adding/replacing datasets during a demo.
